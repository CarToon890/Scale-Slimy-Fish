# 🎣 Scale Slimy Fish — Auto Fishing Bot (100% Vision-Based)

บอทตกปลาอัตโนมัติประสิทธิภาพสูงสำหรับเกม **[Scale Slimy Fish](https://www.roblox.com/games/82208825713916/Scale-Slimy-Fish)** บน Roblox  
ทำงานผ่านเทคโนโลยี **100% External Computer Vision (MSS + OpenCV)** และการจำลองสัญญาณคลิกเมาส์ระดับฮาร์ดแวร์ ปลอดภัย ไม่มีการดัดแปลงไฟล์เกม ไม่ฉีดสคริปต์ (No Injection) และป้องกันการถูกตรวจจับ

## 🌟 ฟีเจอร์หลัก (Key Features)

- **💎 Minimalist Frosted Glass & Luxury Dark UI:** หน้าต่างโปรแกรมดีไซน์ใหม่สไตล์ Apple macOS Pro Dark Mode สวยหรู สบายตา พร้อม 3 Segmented Metric Cards (`Casts`, `Fish Caught`, `Perfect Rate`), แบดจ์สถานะ Pill Badge มน, และแถบความคืบหน้าแบบมินิมอล
- **🏛️ 6-State Finite State Machine (FSM):** โครงสร้างการทำงาน 6 สเตตัสเต็มรูปแบบ:
  1. `STATE 0: IDLE` (เตรียมความพร้อม & จัดตำแหน่งเมาส์ใน Safe Water Zone)
  2. `STATE 1: CASTING` (ชาร์จเกจพลังงานตรวจจับแถบสีเขียวล็อก Perfect Cast)
  3. `STATE 2: SINKING` (รอสายเบ็ดจมน้ำ พร้อม Dual-Anchor สแกน `Hold to fish` / `!`)
  4. `TRANSITION: REACTION` (หน่วงเวลาตอบสนองเมื่อปลาติดเบ็ดก่อนส่ง MouseDown)
  5. `STATE 3: REELING` (กดคลิกซ้ายค้างดึงปลา + Micro-Jitter 120ms + ตรวจสอบปุ่ม Cancel)
  6. `STATE 4: LOOT & RESET` (รอการ์ดแสดงผลปลา คลิกข้ามและเตรียมเหวี่ยงเบ็ดยกถัดไป)
- **🛑 Universal Cancel Interception:** หากตรวจพบปุ่มวงกลมสีแดง **Cancel** บนหน้าจอระหว่างอยู่ในสถานะ `STATE 0 (IDLE)`, `STATE 1 (CASTING)` หรือ `STATE 4 (LOOT & RESET)` บอทจะตัดเข้าสู่ `STATE 3: REELING` เพื่อดึงปลาทันที (สำหรับ `STATE 2: SINKING` สายเบ็ดจะจมน้ำตามธรรมชาติและรอสัญญาณ `Hold to fish` / `!` เพื่อดึงปลา)
- **🔄 Cancel Auto-Extension Loop:** เมื่อเปิดสวิตช์ Extension บอทจะกดคลิกซ้ายค้างดึงต่อไปเรื่อยๆ จนกว่าปุ่ม Cancel จะหายไปจากหน้าจอ (ปลาลอยขึ้นผิวน้ำครบ $100\%$)
- **⚡ Fast Cancel Reset:** เมื่อปิดสวิตช์ Extension หากครบเวลาแล้วปลายังไม่ขึ้น บอทจะกดปุ่ม Cancel เพื่อตัดสายและวนกลับไปเหวี่ยงเบ็ดใหม่ทันที
- **🎒 Rod Capacity Multiplier:** รองรับสเปกคันเบ็ด `Cap:` (จำนวนปลาที่ตกได้ต่อรอบ) โดยระบบจะคำนวณและสะสมสถิติปลาจริง (เช่น เหวี่ยงติด 10 ครั้ง $\times 10\text{ Cap} = 100\text{ ตัว}$)
- **🚨 Global Interrupt Layer:** ป้องกันปัญหาบอทติดค้างเมื่อตกได้ปลาหายากระดับ **Legendary** โดยตรวจจับและคลิกข้ามหน้าต่าง *"Click to Continue"* อัตโนมัติ ($99.99\%$ Accuracy)
- **🎒 ตรวจจับกระเป๋าเต็ม (Inventory Full Auto-Pause):** สแกนหาข้อความเตือนกระเป๋าเต็มสีแดง *"Inventory full"* บนหน้าจอจริง แล้วสั่งหยุดบอทชั่วคราว พร้อมแสดงแถบเตือนสีแดง
- **🎯 Visual ROI Calibration & Live Diagnostic:** เครื่องมือตีกรอบกำหนดพื้นที่ตรวจจับ 5 จุดสำคัญผ่าน GUI ในแท็บ `[⚙️ ตั้งค่า]` พร้อมปุ่ม `🧪 ทดสอบสแกนทั้ง 5 จุด (Live Vision Test)`
- **🔍 HD Template Inspector Modal:** หน้าต่างพรีวิวตรวจสอบแม่แบบ `TemplateInspectorDialog` ซูมได้ 2x–3.5x พร้อมตัววัดขนาดพิกเซลและปุ่มบันทึก/แคปใหม่
- **📹 Dual Live Camera Monitors (`205x120px`):** จอแสดงผลการจับภาพแบบสดความละเอียดสูง แสดงกรอบ Overlays แยกสีตามแต่ละสถานะ
- **🛡️ Anti-AFK & Micro-Jitter (120ms):** สั่นเคอร์เซอร์เมาส์แบบไมโครทุกๆ 120ms ป้องกันอาการคลิกหลุด และขยับตัวละครเบาๆ ป้องกัน Roblox ตัดการเชื่อมต่อ

## 🧮 การคำนวณฟิสิกส์คันเบ็ด (Rod Physics & Calculator)

ผู้เล่นสามารถกรอกสเปกคันเบ็ดในหน้าหลักได้ 3 ค่า:
1. **Depth (ความลึก):** ระยะที่สายเบ็ดจมลงสู่ใต้ทะเล (เช่น `380m`)
2. **Str (แรงดึง):** พลังความเร็วในการดึงปลา (เช่น `117`)
3. **Cap (ความจุต่อรอบ):** จำนวนปลาที่คันเบ็ดเกี่ยวติดขึ้นมาได้พร้อมกันใน 1 การเหวี่ยง (เช่น `10 ตัว/ครั้ง`)

$$\text{Reeling Hold Duration} = \left(\frac{\text{Depth}}{\max(1, \text{Str})}\right) \times 1.65 + 0.5\text{ วินาที}$$

$$\text{Sinking Timeout} = \max\left(18.0, \frac{\text{Depth}}{12.0} + 5.0\right)\text{ วินาที}$$

## 🚀 วิธีเปิดใช้งานบอท (How to Run)

1. **เปิดโปรแกรม:** ดับเบิ้ลคลิกที่ไฟล์ **`start_bot.bat`** (หรือรัน `python main.py`)
2. **เข้าเกม Roblox:** ถือคันเบ็ดไว้ในมือ และยืนหันหน้าเข้าหาผิวน้ำ
3. **กรอกสเปกคันเบ็ด:** ใส่ค่า `Depth`, `Str`, และ `Cap` ของคันเบ็ดของคุณในแท็บ **[🎣 หน้าหลัก]**
4. **ปุ่มลัดสั่งการทำงาน (Hotkeys):**
   - กดปุ่ม **`[F6]`** $\rightarrow$ **เริ่มทำงาน (Start Bot)**
   - กดปุ่ม **`[F7]`** $\rightarrow$ **หยุดการทำงานฉุกเฉิน (Stop Bot)**

| 🚨 **Global Interrupt** | เปิด / ปิด | ตรวจจับและปิดหน้าต่าง "Click to Continue" ปลาระดับ Legendary อัตโนมัติ |

| 🔄 **Failsafe Recovery** | เปิด / ปิด | กู้คืนมุมกล้องและสเตตัสตัวละครอัตโนมัติเมื่อ Timeout ติดต่อกัน 2 ครั้ง |

## 🎯 เครื่องมือกำหนดพื้นที่ตรวจจับ (Visual ROI Calibration & Diagnostics)

5. **`🎒 Inv Full`**: กำหนดกรอบแถบเตือนกระเป๋าเต็ม (Inventory full)
6. **`🧪 ทดสอบสแกนทั้ง 5 จุด (Live Vision Test)`**: ปุ่มวิเคราะห์สดแบบเรียลไทม์ พร้อมสรุปสถานะการตรวจจับทั้ง 5 จุด

## ❓ การแก้ปัญหาเบื้องต้น (Troubleshooting & FAQ)

### Q1: ดับเบิ้ลคลิก `start_bot.bat` แล้วหน้าต่างปิดตัวเองทันที?
> **วิธีแก้:** ตรวจสอบว่าได้ติดตั้ง Python และติ๊ก `Add Python to PATH` แล้วหรือยัง จากนั้นเปิด CMD แล้วรัน `pip install -r requirements.txt` ซ้ำอีกครั้ง

### Q2: กด F6 แล้วบอทไม่ทำงานบนโน้ตบุ๊ก?
> **วิธีแก้:** โน้ตบุ๊กบางรุ่นต้องกดปุ่ม `Fn + F6` หรือสามารถกดปุ่ม **`▶ เริ่ม (F6)`** สีเขียวบนหน้าต่างโปรแกรมแทนได้

### Q3: บอทตรวจไม่เจอข้อความ "Hold to fish"?
> **วิธีแก้:** ให้กดปุ่ม **`📸 แคป Hold`** บนหน้าต่างโปรแกรม แล้วลากกรอบครอบตัวหนังสือ *"Hold to fish"* บนจอเกมของคุณ 1 ครั้งเพื่อสร้างแม่แบบใหม่ที่ตรงกับขนาดจอของคุณ
