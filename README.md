# 🎣 Scale Slimy Fish — Auto Fishing Bot (100% Vision-Based)

บอทตกปลาอัตโนมัติประสิทธิภาพสูงสำหรับเกม **[Scale Slimy Fish](https://www.roblox.com/games/82208825713916/Scale-Slimy-Fish)** บน Roblox  
ทำงานผ่านเทคโนโลยี **100% External Computer Vision (MSS + OpenCV)** และการจำลองสัญญาณคลิกเมาส์ระดับฮาร์ดแวร์ ปลอดภัย ไม่มีการดัดแปลงไฟล์เกม ไม่ฉีดสคริปต์ (No Injection) และป้องกันการถูกตรวจจับ

---

## 🌟 ฟีเจอร์หลัก (Key Features)

- **🏛️ 6-State FSM Architecture:** โครงสร้างการทำงาน 6 สเตตัสเต็มรูปแบบ (IDLE $\rightarrow$ CASTING $\rightarrow$ SINKING $\rightarrow$ TRANSITION $\rightarrow$ REELING $\rightarrow$ LOOT & RESET)
- **🚨 Global Interrupt Layer:** ป้องกันปัญหาบอทติดค้าง (Deadlock) เมื่อตกได้ปลาหายากระดับ **Legendary** โดยตรวจจับและคลิกข้ามหน้าต่าง *"Click to Continue"* อัตโนมัติ ($99.99\%$ Accuracy)
- **🎒 ตรวจจับกระเป๋าเต็ม (Inventory Full Auto-Pause):** สแกนหาข้อความเตือนกระเป๋าเต็มสีแดง *"Inventory full"* แล้วสั่งหยุดบอทชั่วคราว พร้อมแสดงแถบเตือนสีแดง ไม่เหวี่ยงเบ็ดทิ้งฟรี
- **⚡ 1ms High-Resolution OS Timer:** เปิดใช้งาน Windows Multimedia Timer ความละเอียดระดับ $1\text{ Millisecond}$ เวลานับถอยหลังตรงเป๊ะ ไม่มีอาการดีเลย์สะสม
- **🟢/🔴 Live Rod Status LED:** แสดงไฟสถานะสายเบ็ดบนบกและในน้ำแบบ Real-time แยกแยะชัดเจน ไม่เกิด False Positive
- **🎯 Dual-Anchor Bite Detection:** ตรวจจับทั้งข้อความ *"Hold to fish"* และไอคอนตกใจสีแดง **`!`** เหนือหัวตัวละครแบบ Zero-Latency
- **📱 Compact Side-Panel GUI (`440x680px`):** หน้าต่างขนาดกะทัดรัด พร้อมปุ่ม **📌 ปักหมุดลอย (Always-on-Top)** สำหรับเปิดคู่กับหน้าต่างเกม Roblox
- **🎛️ ปรับแต่งเวลาได้อิสระ:** สไลเดอร์ Min Charge Gate ($0-1500\text{ms}$), Fast Recast Delay ($0.2-8.0\text{s}$), Bite Reaction ($0-2000\text{ms}$) และ Max Sinking Timeout ($5.0-90.0\text{s}$)

## 🚀 วิธีเปิดใช้งานบอท (How to Run)

### 1. เปิดโปรแกรม
- **ดับเบิ้ลคลิกที่ไฟล์:** **`start_bot.bat`**  
*(หรือเปิด Terminal ในโฟลเดอร์แล้วพิมพ์ `python main.py`)*

### 2. เตรียมตัวในเกม Roblox
1. เข้าเล่นเกม **Scale a Slimy Fish** ใน Roblox
2. ถือ **เบ็ดตกปลา (Fishing Rod)** ไว้ในมือ (Slot 1)
3. ยืนบริเวณริมฝั่งและหันหน้าตัวละครเข้าหาผิวน้ำ

### 3. ตั้งค่าสเปกคันเบ็ด (บนหน้าต่างบอท)
- กรอกค่า **Depth (ความลึก)** และ **Str (แรงดึง)** ของคันเบ็ดของคุณในแท็บ **[🎣 หน้าหลัก]** ระบบจะคำนวณเวลาการดึงเบ็ดและเวลาสายเบ็ดจมน้ำให้อัตโนมัติ

### 4. ปุ่มลัดสั่งการทำงาน (Hotkeys)
- กดปุ่ม **`[F6]`** บนคีย์บอร์ด $\rightarrow$ **เริ่มทำงาน (Start Bot)**
- กดปุ่ม **`[F7]`** บนคีย์บอร์ด $\rightarrow$ **หยุดการทำงานฉุกเฉิน (Stop Bot)**

## ❓ การแก้ปัญหาเบื้องต้น (Troubleshooting & FAQ)

### Q1: ดับเบิ้ลคลิก `start_bot.bat` แล้วหน้าต่างปิดตัวเองทันที?
> **วิธีแก้:** ตรวจสอบว่าได้ติดตั้ง Python และติ๊ก `Add Python to PATH` แล้วหรือยัง จากนั้นเปิด CMD แล้วรัน `pip install -r requirements.txt` ซ้ำอีกครั้ง

### Q2: กด F6 แล้วบอทไม่ทำงานบนโน้ตบุ๊ก?
> **วิธีแก้:** โน้ตบุ๊กบางรุ่นต้องกดปุ่ม `Fn + F6` หรือสามารถกดปุ่ม **`▶ เริ่ม (F6)`** สีเขียวบนหน้าต่างโปรแกรมแทนได้

### Q3: บอทตรวจไม่เจอข้อความ "Hold to fish"?
> **วิธีแก้:** ให้กดปุ่ม **`📸 แคป Hold`** บนหน้าต่างโปรแกรม แล้วลากกรอบครอบตัวหนังสือ *"Hold to fish"* บนจอเกมของคุณ 1 ครั้งเพื่อสร้างแม่แบบใหม่ที่ตรงกับขนาดจอของคุณ
