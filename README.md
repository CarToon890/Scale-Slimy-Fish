# 🎣 Scale Slimy Fish — Auto Fishing Bot (คู่มือการใช้งาน)

โปรแกรม Auto Fishing Bot ประสิทธิภาพสูงสำหรับแมพ **Scale Slimy Fish** ใน Roblox ทำงานผ่าน **100% External Computer Vision (MSS + OpenCV)** และจำลองสัญญาณคลิกเมาส์ระดับฮาร์ดแวร์ ปลอดภัย ไม่ดัดแปลงไฟล์เกมและไม่โดนแบน

---

## 🌟 ฟีเจอร์ใหม่ล่าสุด (Latest Features)

1. **Dual Detection Engine (ระบบตรวจจับ 2 โหมด)**:
   - ⚡ **โหมด Auto Scan ทั่วจอ (แนะนำ):** ค้นหาตำแหน่งแถบเกจพลังและข้อความ "Hold to fish" ทั่วทั้งหน้าจอแบบอัตโนมัติ ไม่ต้องเสียเวลาลากกรอบ
   - 🎯 **โหมด Manual ROI:** สำหรับผู้ใช้ที่ต้องการลากกรอบกำหนดพิกัดเฉพาะเจาะจงด้วยตัวเอง
2. **Real-time Continuous Live Camera (~10 FPS):**
   - หน้าต่างโปรแกรมจะดึงภาพสดจากจอเกม Roblox ตลอดเวลาแบบ Real-time แสดงผลการตรวจจับสีเขียวและข้อความแบบเคลื่อนไหวสด ยืนยันว่าระบบไม่อ่านจากภาพนิ่งเก่า
3. **Bite Reaction Delay & Clean Mouse Reset:**
   - ส่ง `MouseUp` เคลียร์สถานะปุ่มเมาส์ และหน่วงเวลา 350ms ก่อนเริ่มกดค้างดึงปลา ป้องกันเกมมองว่ากดค้างต่อเนื่องมาจากตอนเหวี่ยงเบ็ด
4. **Paced 5-State Engine:**
   - หน่วงเวลาชาร์จขั้นต่ำ (Min Charge Gate 450ms) ป้องกันบอทปล่อยเมาส์เร็วเกินไป

---

## 🏛️ สถาปัตยกรรมการทำงาน (5-State Engine)

```
[STATE 0: IDLE / READY]
       │  (ย้ายเคอร์เซอร์ไป Safe Zone 50%, 38% -> หน่วงเวลา 0.8s)
       ▼
[STATE 1: CASTING] ────────► ส่ง MouseDown ชาร์จเกจ (หน่วงขั้นต่ำ 450ms)
       │                     สแกนหาพิกเซลสีเขียว 10–15% ด้านบนสุด (Backup 1.4s) -> ส่ง MouseUp (Perfect !)
       ▼                     หน่วงเวลาทุ่นตกน้ำ 1.2s
[STATE 2: SINKING] ────────► สายเบ็ดจมลงสู่ใต้ทะเล (Depth: 0m -> 280m)
       │                     สแกนหาข้อความ "Hold to fish" (Safety Timeout: 14.0s)
       ▼ (ตรวจพบข้อความ)
[TRANSITION: REACTION DELAY] ─► ส่ง MouseUp ซ้ำเคลียร์สถานะ + รอ 350ms ให้เกมเปิดรับคำสั่ง
       ▼
[STATE 3: REELING] ────────► ส่ง MouseDown สดใหม่ + ส่ง Micro-Jitter ทุก 120ms (+1px/-1px)
       │                     สิ้นสุดเมื่อข้อความหายไปต่อเนื่อง 3 เฟรม (~200ms Debounce) -> ส่ง MouseUp
       ▼
[STATE 4: LOOT_RESET] ─────► รอการ์ดปลาแสดงผล & ตัวละครเซ็ตตัว (หน่วงเวลา 2.6s)
       │
       └───────────────────► วนลูปกลับไปเริ่ม STATE 1 อัตโนมัติ
```

## 🚀 วิธีเริ่มต้นใช้งานอย่างรวดเร็ว (Quick Start)

### 1. เปิดโปรแกรม
- ดับเบิ้ลคลิกไฟล์ **`start_bot.bat`** (หรือเปิด Terminal แล้วรัน `python main.py`)

### 2. เตรียมตัวในเกม Roblox
1. เข้าเกม Roblox แมพ **Scale a Slimy Fish**
2. ถือ **เบ็ดตกปลา (Fishing Rod)** ไว้ในมือ
3. ยืนหันหน้าเข้าหาผิวน้ำ

### 3. เลือกโหมดการตรวจจับ
- **⚡ โหมด Auto Scan ทั่วจอ (ค่าเริ่มต้น):** บอทจะค้นหาเกจและข้อความอัตโนมัติ สามารถกด **`F6`** เริ่มทำงานได้ทันที!
- **🎯 โหมด Manual ROI:** หากต้องการระบุพิกัดเอง ให้กดปุ่ม `🎯 ลากเลือกพื้นที่...` บนการ์ด 1 และ 2

### 4. เริ่มต้น / หยุดบอท (Global Hotkeys)
- กด **`F6`** บนคีย์บอร์ด เพื่อสั่งให้บอทเริ่มทำงาน
- กด **`F7`** บนคีย์บอร์ด เพื่อสั่งหยุดการทำงานฉุกเฉิน

## ⏱️ การปรับแต่งเวลาและความเร็ว (Pacing Controls)

* ⚡ **เวลาชาร์จขั้นต่ำ (Min Charge Gate - ค่าเริ่มต้น 450ms):**
  - บังคับกดค้างขั้นต่ำก่อนเริ่มตรวจจับสีเขียว เพื่อให้หลอดเกจมีเวลาวิ่งขึ้นมาจริง ๆ และไม่ปล่อยเมาส์ทันที
* 🐟 **เวลาตอบสนองดึงเบ็ด (Bite Reaction Delay - ค่าเริ่มต้น 350ms):**
  - หน่วงเวลาให้เกม Roblox สลับเข้าสู่สถานะพร้อมดึงเบ็ด ก่อนส่งสัญญาณคลิกค้างสดใหม่
* ⏳ **เวลาหน่วงหลังตกเสร็จ (Recast Delay - ค่าเริ่มต้น 2.6s):**
  - ปรับเวลารอเพื่อให้แอนิเมชันปลาและการ์ดแสดงผลครบถ้วน ก่อนเริ่มเหวี่ยงเบ็ดรอบถัดไป
